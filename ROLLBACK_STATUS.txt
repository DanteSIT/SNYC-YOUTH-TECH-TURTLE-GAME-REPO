#  WHAT WAS WRONG. Two separate defects, both reported by eye as "the floor is
#  on the wrong direction" and "the side is on the wrong side":
#
#    1. WINDING INVERTED. Godot's front faces are CLOCKWISE, so a triangle is
#       front-facing iff its right-hand-rule normal points AWAY from the viewer.
#       The OpenGL assumption is the exact opposite. The seabed was wound with
#       +Y normals, which is a BACK face for a camera above it, so cull_back in
#       shaders/sand.gdshader hid the whole bed and showed only its underside.
#       tools/probe_seabed.gd had asserted n.y > 0.5, i.e. the OpenGL
#       assumption, so the validator agreed with the bug and reported 16/16 OK.
#    2. SKIRT ON THE WRONG EDGE. The bed spans x = -8..+5 and the player camera
#       sits at x = +3.576 looking along -X, so the +X edge is 1.4 m BEHIND the
#       camera and can never appear. The skirt was hung there, where it was
#       invisible and did nothing, while the edge that actually ends in view at
#       x = -8 had no wall behind it.
#
#  FIXES.
#    * tools/fix_seabed.py: REVERSE/--unflip replaced by INVERT_WINDING=false /
#      --invert-winding, defaulting to the winding that puts the top surface's
#      right-hand normal at -Y and the skirt's at -X, i.e. both facing the
#      camera. Skirt moved from BED_X + x_half to BED_X - x_half.
#    * tools/probe_seabed.gd: now requires n.y < -0.5 for the top and n.x < -0.9
#      for the skirt, and says which failure it saw.
#    * tools/probe_winding.gd (new): measures the engine's convention by
#      rendering one quad in both windings under cull_back and comparing against
#      a cull_disabled control. Self-calibrating, because the first version of
#      this test read one frame per winding with no warm-up and no control,
#      returned a non-zero count for a fully culled face, and led to a SECOND
#      wrong winding fix. It now also needs a warm-up and a control covering
#      >25% of the frame, and fails loudly rather than guessing.
#    * tools/shot.gd: hide= now accepts /root/... so autoloads are reachable
#      (DebugStats is at /root/DebugStats and lands in every capture otherwise),
