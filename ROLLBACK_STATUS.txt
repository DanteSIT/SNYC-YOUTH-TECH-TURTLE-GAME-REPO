# -----------------------------------------------------------------------------
#  BEFORE YOU ROLL BACK
# -----------------------------------------------------------------------------
#
#  * ALWAYS commit or stash your current work first, or reset --hard will
#    destroy it:
#        git add -A && git commit -m "WIP before rollback"
#     or
#        git stash push -u -m "WIP before rollback"
#    (the -u matters: 45 files here are untracked and reset will delete them)
#
#  * Check what you are about to lose:
#        git diff --stat BASELINE-pre-seabed
#        git status --short
#
#  * Untracked files are the real danger. `git reset --hard` DELETES files that
#    are not in the target commit. Use `git stash push -u` first if unsure.
#
#  * .godot/ (the import cache) is gitignored. After any rollback run the
#    editor once, or delete .godot/ if scenes fail to load — the .import files
#    can point at files a rollback removed.
